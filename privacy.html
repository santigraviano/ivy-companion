Privacy policy

Last updated: 27 October 2026

Ivy Companion ("Ivy") is a personal assistant used only by its developer on their own computer. This policy covers the Google user data Ivy accesses.

Data accessed

Ivy requests read-only access to Google Calendar (https://www.googleapis.com/auth/calendar.readonly): the list of calendars and the events on them (titles, times, locations, descriptions and attendee response status).

How it is used

Calendar data is used only to answer the user's own questions about their schedule and to include upcoming events in the assistant's context. It is not used for advertising, profiling, or training AI models.

Storage

The OAuth refresh token is stored in a file on the user's own Mac, readable only by that user. Event data is fetched on demand and held briefly in memory; it is not kept in any database or on any server operated by Ivy.

Sharing

Google user data is not sold or shared with third parties. To answer a question, relevant event details may be sent as part of the prompt to the AI model provider the user has configured (for example Anthropic), under that provider's terms; that provider does not get access to the Google account.

Limited Use

Ivy's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions or by running ivy google logout, which also deletes the stored token.
